### Сущности доменной модели
- `User` - пользователь системы (email, отображаемое имя, роль).
- `Asset` - криптоактив (тикер, название, описание, сайт, логотип); справочник для пар и листинга.
- `Exchange` - биржа (название, сайт, логотип).
- `Listing` - событие листинга на конкретной бирже (статус, дата, описание); опционально основной актив (`assetId`).
- `TradingPair` - торговая пара в рамках листинга (ссылки на `Asset` base/quote).
- `MarketNews` - новость для блока «новости рынка» (заголовок, дата, медиа, краткий текст, ссылка, порядок); привязана к бирже (`exchangeId`).
- `Feedback` - отзыв пользователя.
- `Favorite` - связь «пользователь - избранный листинг».

### Связи между сущностями
- `Exchange 1 -> N Listing`
- `Exchange 1 -> N MarketNews`
- `Asset 1 -> N Listing` (основной актив листинга, опционально)
- `Asset 1 -> N TradingPair` как базовый и как котируемый актив
- `Listing 1 -> N TradingPair`
- `User 1 -> N Feedback`
- `User N <-> N Listing` через `Favorite`
